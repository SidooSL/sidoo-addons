# Base Apps Menu Hide

Módulo que restringe el acceso al menú principal de Apps solo para administradores.

## Descripción

Este módulo oculta el menú de **Apps** en la interfaz de Odoo, permitiendo que solo los administradores puedan acceder a él. Esto es útil para restringir el acceso de usuarios normales a la instalación de módulos y otras funciones administrativas.

## Características

- Restringe el menú de Apps a administradores
- Interfaz simplificada para usuarios normales
- Sin dependencias adicionales

## Instalación

1. Copiar el módulo en el directorio de addons de Odoo
2. Actualizar la lista de módulos
3. Instalar "Base Apps Menu Hide"

## Versión

- **Versión**: 18.0.1.0.0
- **Compatible con**: Odoo 18.0+
