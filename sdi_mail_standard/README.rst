=============
Mail SDI Base
=============

Proposito
=========

Este modulo proporciona una base reutilizable de comunicaciones para proyectos
Odoo, agrupando en un unico punto de instalacion un conjunto seleccionado de
modulos OCA del repositorio `mail`.

Modulos que instala
===================

* mail
* mail_composer_cc_bcc
* mail_debrand
* mail_forward
* mail_layout_force
* mail_notification_custom_subject
* mail_no_user_assignation_notification
* mail_optional_autofollow
* mail_optional_follower_notification
* mail_suggested_recipient_unchecked
* mail_tracking

Enfoque
=======

Este modulo esta pensado como una base comun reutilizable para clientes. No
incorpora logica de negocio por si mismo y queda preparado para centralizar
futuras ampliaciones relacionadas con correo de forma controlada.
