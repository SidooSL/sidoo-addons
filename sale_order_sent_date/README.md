# Module: Sale Order Sent Date

## Purpose

Automatically stores the sent date and time each time a sales quotation transitions to "Quotation Sent".

## Use Cases

- Commercial audit of the latest quotation sent event.
- Metrics between quotation creation and the latest sent event.
- Sales cycle traceability on quotations and orders.

## Configuration

- Required dependency: `sale`.
- No additional parameters are required.
- The `Sent Date` field is displayed on the sales order form, after `Order Date`.
