This module extends the functionality of the account payment order module by adding a transition account to the payment mode.


**Notable features:**

Easily select a transition account in the payment mode.

#. Enables the use of a transition account for account move lines in the payment mode.

Usage
=====

To use the functionality of this module, you need to:

#. Go to *Accounting / Payment Mode*
#. Enable the option to use a transition account in the payment mode.
#. Choose the target account where you want to use the transition account.
#. Ensure that the transition account is correctly set up this account must have the type assets
