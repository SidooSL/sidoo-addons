=====================================
Partner Opportunity Attachments
=====================================

This module adds a smart button to the partner form view that provides quick access to view all attachments associated with CRM leads (opportunities) for that specific partner.

**Table of contents**

.. contents::
   :local:

Features
========

* **Smart Button**: Adds a "CRM Attachments" smart button to the partner form view
* **Centralized Access**: View all attachments from CRM leads/opportunities related to a partner in one place
* **Read-Only View**: Provides a safe, read-only view of attachments (create and edit are disabled)
* **Intuitive Navigation**: Easy access to lead attachments directly from the partner record

Configuration
=============

No additional configuration is required. The module works out of the box once installed.

Usage
=====

1. Navigate to any partner record (Contacts menu)
2. Look for the "CRM Attachments" smart button in the top-right button area
3. Click the button to view all attachments from CRM leads associated with this partner
4. The attachment list will open showing only relevant files in read-only mode

Use Cases
=========

* **Sales Teams**: Quickly access all documents shared during the sales process for a specific customer
* **Customer Support**: Review all attachments from previous opportunities when handling support requests
* **Account Management**: Get a complete view of all documents exchanged with a client across multiple opportunities
* **Compliance**: Easily locate all documentation related to a partner's CRM activities
