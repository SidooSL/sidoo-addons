🚨 POS Decimal Discount Fix

Versiones afectadas: 14.0, 15.0, 16.0

Módulos Base Requeridos

  • point_of_sale (Odoo core)
  • pos_discount (Odoo core)

Configuración Afectada

  • Descuentos Generales: Activados
  • Idioma: Español

Descripción del Problema

Se ha detectado un problema en el Point of Sale (POS) cuando se aplican descuentos generales con valores decimales. El sistema no interpreta correctamente los valores decimales cuando el idioma está configurado en español.

Causa Técnica

// Ejemplo del problema:
parseFloat("10,5") → 10 // Resultado incorrecto
parseFloat("10.5") → 10.5 // Resultado esperado

La función JavaScript parseFloat recibe el valor con coma decimal ("10,5") en lugar del punto decimal ("10.5") esperado, causando que los decimales se pierdan durante la conversión.

Observaciones Importantes

  • Los descuentos por línea funcionan correctamente
  • El problema no ocurre cuando el idioma está configurado en inglés
  • El error ha sido corregido en Odoo 17.0

Estado de la Corrección

Este módulo proporciona una solución para las versiones afectadas (14.0 - 16.0), asegurando que los descuentos decimales se procesen correctamente independientemente del idioma configurado en el sistema.
