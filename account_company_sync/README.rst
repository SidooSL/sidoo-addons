This module provides a wizard that allows users to select accounts from Odoo’s chart of accounts and create those accounts across multiple selected companies


**Notable features:**

Easily select and replicate accounts across multiple companies.

#. Ensures consistency in account setups across selected companies.

#. Saves time by automating account creation in multi-company setups

Usage
=====

To use the functionality of this module, you need to:

#. Go to *Accounting / Configuration*. Here, you’ll find a menu item to open the account replication wizard.
#. In the wizard, select the accounts you want to create in other companies.
#. Choose the target companies where you want these accounts to be replicated, by default the allowed companies of the user
#. Click on Sync to create the accounts in the selected companies.
#. Alternatively, in the chart of accounts list view, you can select the accounts you wish to replicate and use the action available in the list to open the wizard.

Asset Management Compatibility
==============================

This module is compatible with both asset management systems:

* **OCA account_asset_management**: Uses the ``asset_profile_id`` field
* **Odoo Enterprise account_asset**: Uses the ``asset_model`` field

The module automatically detects which asset management module is installed and synchronizes the appropriate asset field when replicating accounts across companies.
