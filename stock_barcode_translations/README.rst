# Stock Barcode Translations

Este módulo proporciona traducciones al español para el módulo `stock_barcodes` de Odoo 14.0.

## Características
- Traduce al español los textos y etiquetas del módulo `stock_barcodes`.
- Facilita el uso del escaneo de códigos de barras en almacén para usuarios hispanohablantes.

## Instalación
1. Copie este módulo en su carpeta de addons personalizada.
2. Asegúrese de tener instalado el módulo `stock_barcodes`.
3. Instale el módulo desde la interfaz de Odoo o mediante la línea de comandos.

## Dependencias
- `stock_barcodes`

## Uso
Una vez instalado, las etiquetas y textos del módulo de códigos de barras de inventario aparecerán traducidos al español.
