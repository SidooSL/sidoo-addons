This module is used to create a return from a sale order. It will look for the outgoing delivery notes for this customer containing the same product we have in negative.


**Notable features:**

* Create a return from a sale order. using the same product in negative quantity.
* Look for the outgoing delivery notes for this customer containing the same product we have in negative.

Usage
=====

To use the functionality of this module, you need to:

#. Go to the new menu item under *Sales / Returns*.
#. Click on any sale order.
#. Click on the *Create Return* button.
#. Click on return button to create new *IN* picking.
