This module extends the functionality of the account payment order extension module by using transition account when grouped moves.


**Notable features:**

Use transition account when grouped moves.

#. Enables the use of a transition account for account move lines in the payment mode when grouped moves is set up.

Usage
=====

To use the functionality of this module, you need to:

#. Ensure that the account payment order extension module is installed.
#. Ensure that the transition account is correctly set up for payment mode.
#. When grouped moves is set up, the transition account will be used for the account move lines.
